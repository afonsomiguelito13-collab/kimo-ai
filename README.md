# 📱 Kimo AI (Versão APK Mobile)

O **Kimo AI** é uma interface minimalista e otimizada de Inteligência Artificial para dispositivos móveis Android. O projeto foi desenhado para ser compilado e executado como um **APK WebView**, permitindo carregar e gerir modelos LLM locais no formato `.gguf`.

---

## 🚀 Funcionalidades

* **Apenas Mobile / APK**: Bloqueio automático de navegação em computadores (PC) ou navegadores tradicionais, garantindo a execução exclusiva no ambiente WebView.
* **Leitor de Modelos Local (.gguf)**: Suporte para seleção e carregamento de ficheiros `.gguf` guardados diretamente no dispositivo.
* **Renderização de Markdown Completa**: Suporte total para tabelas, listas e formatadores de texto.
* **Blocos de Código com Botão Copiar**: Formatação destacada para linguagens como HTML, CSS, JavaScript, Lua e Luau, com botão integrado para copiar todo o código num toque.
* **Interface Tema Escuro (Dark Mode)**: Layout responsivo inspirado em aplicações modernas de chat.
